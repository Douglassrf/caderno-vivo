# Checklist de Lançamento Comercial — Caderno Vivo

## Segurança
- [ ] RLS ativo nas tabelas sensíveis.
- [ ] Teste Anti-IDOR aprovado em Supabase real.
- [ ] Teste de segurança de produto aprovado.
- [ ] Edge Functions protegidas.
- [ ] Buckets com acesso restrito.

## Produto
- [ ] Fluxo principal de composição funcionando.
- [ ] Dossiê funcionando.
- [ ] Exportação protegida funcionando.
- [ ] Planos Plus/Prime refletidos por entitlements.
- [ ] Limites por plano conferidos.

## Pagamento
- [ ] Checkout sandbox validado.
- [ ] Webhook validado.
- [ ] Entitlement criado somente após pagamento aprovado.
- [ ] Falha de pagamento não libera recurso.
- [ ] Cancelamento/revogação mapeado.

## Deploy
- [ ] Variáveis reais configuradas.
- [ ] Build/deploy validado.
- [ ] Domínio definido.
- [ ] Política de privacidade publicada.
- [ ] Termos de uso publicados.

## Operação
- [ ] Canal de suporte definido.
- [ ] Plano de rollback documentado.
- [ ] Backup/exportação de dados planejado.
- [ ] Monitoramento mínimo ativo.
