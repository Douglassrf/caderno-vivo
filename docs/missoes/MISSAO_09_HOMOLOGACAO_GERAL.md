# Missão 9 — Homologação Geral

## Objetivo
Consolidar o projeto antes do lançamento comercial, validando segurança, autenticação, persistência, pagamentos, entitlements, exportações e deploy.

## Checklist de homologação
```txt
[ ] Supabase real configurado
[ ] Migrations aplicadas
[ ] RLS validado
[ ] Edge Functions publicadas
[ ] Teste Anti-IDOR aprovado
[ ] Teste de segurança de produto aprovado
[ ] Login real validado
[ ] Migração localStorage -> Supabase validada
[ ] Multiusuário validado
[ ] Mercado Pago sandbox validado
[ ] Webhook cria entitlement
[ ] Exportação protegida por URL assinada
[ ] Deploy readiness aprovado
[ ] Backup e rollback documentados
```

## Veredito técnico
Após esta missão, o projeto fica pronto para a Missão 10: lançamento comercial controlado.
