# Caderno Vivo V3.5

Versão consolidada do Caderno Vivo com arquitetura V2 + V2.1 + V3 + V3.5.

## Entregas incluídas

- Fase 01 — MVP Interface
- Missão 02 — Caderno do Compositor
- Missão 03 — Minhas Obras
- Missão 04 — Maestro IA
- Missão 05 — Profissional
- Missão 06 — Jornada do Artista
- Missão 07 — Painel de Evolução
- Missão 08 — Conquistas Reais
- Missão 09 — Auditoria Final Geral
- Missão 10 — Pacote final para GitHub e Vercel

## Rodar localmente

```bash
npm install
npm run build
```

Abra `index.html` em um servidor estático ou publique na Vercel.
